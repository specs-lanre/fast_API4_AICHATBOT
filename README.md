# FastAPI CI/CD Demo

## Overview

This project demonstrates a complete Continuous Integration and Continuous Deployment (CI/CD) workflow using FastAPI, GitHub, and Railway.

## Features

- REST API with FastAPI
- Automatic deployment
- Git version control
- Railway cloud hosting
- Production-ready configuration

## Tech Stack

- Python
- FastAPI
- Git
- GitHub
- Railway

## Deployment Pipeline

Desktop
↓
Git Commit
↓
GitHub
↓
Railway
↓
Live API
